# QA Test Reports

This directory stores QA test reports generated by agent-driven E2E tests.

## Report Format

Each test run produces two files:

### JSON Report (`qa-{type}-{date}.json`)

Structured data for automated analysis:

```json
{
  "meta": {
    "type": "backend | browser",
    "date": "2026-02-28T14:30:00Z",
    "target_url": "http://YOUR_SERVER_IP",
    "executor": "claude-code-agent",
    "duration_seconds": 120
  },
  "summary": {
    "total": 42,
    "passed": 38,
    "failed": 3,
    "skipped": 1,
    "pass_rate": 0.905
  },
  "suites": [
    {
      "name": "AUTH",
      "status": "pass | fail | partial",
      "tests": [
        {
          "id": "AUTH-01",
          "name": "User signup with valid credentials",
          "status": "pass | fail | skip",
          "duration_ms": 245,
          "details": "",
          "evidence": "screenshots/auth-01-result.png"
        }
      ]
    }
  ],
  "performance": {
    "latencies": {
      "T_signup": { "value_ms": 245, "sla_ms": 500, "pass": true },
      "T_login": { "value_ms": 180, "sla_ms": 500, "pass": true },
      "T_token_create": { "value_ms": 40, "sla_ms": 200, "pass": true }
    }
  },
  "bugs": [
    {
      "id": "B1",
      "severity": "P0 | P1 | P2",
      "title": "Brief description",
      "description": "Detailed description of the bug",
      "reproduction": "Steps to reproduce",
      "affected_suite": "AUTH",
      "affected_test": "AUTH-03"
    }
  ]
}
```

### Markdown Report (`qa-{type}-{date}.md`)

Human-readable summary:

```markdown
# QA Report: {Type} E2E — {Date}

## Target
- URL: {target_url}
- Executor: Claude Code Agent
- Duration: {duration}

## Summary
| Metric | Value |
|--------|-------|
| Total Tests | 42 |
| Passed | 38 |
| Failed | 3 |
| Skipped | 1 |
| Pass Rate | 90.5% |

## Suite Results
### AUTH (PASS)
| ID | Test | Status | Latency |
|----|------|--------|---------|
| AUTH-01 | User signup | ✅ PASS | 245ms |
| AUTH-02 | Duplicate signup | ✅ PASS | 180ms |

### LIVEKIT (FAIL)
| ID | Test | Status | Latency |
|----|------|--------|---------|
| LK-01 | Anonymous token | ✅ PASS | 340ms |
| LK-02 | Agent dispatch | ❌ FAIL | timeout |

## Performance Profile
| Metric | Value | SLA | Status |
|--------|-------|-----|--------|
| T_signup | 245ms | <500ms | ✅ |
| T_login | 180ms | <500ms | ✅ |

## Bugs Found
### B1 (P0) — Brief title
- **Description**: ...
- **Reproduction**: ...
- **Affected**: AUTH-03

## Recommendations
- ...
```

## Naming Convention

```
qa-backend-2026-02-28.json
qa-backend-2026-02-28.md
qa-browser-2026-02-28.json
qa-browser-2026-02-28.md
```

If multiple runs on the same day, append a sequence number:
```
qa-backend-2026-02-28-02.json
```
