# 用户资料页面

## 概述

创建用户资料页面，展示用户基本信息并支持编辑。

## 用户故事

作为 **已登录用户**，我希望 **查看和编辑我的个人资料**，以便 **管理我的账号信息**。

## 功能需求

### 核心功能
- [x] 展示用户头像、昵称、邮箱
- [x] 支持修改头像（从相册选择）
- [x] 支持修改昵称
- [ ] 查看账号绑定状态（Google/Apple）

### 可选功能
- [ ] 支持裁剪头像

## UI/交互要求

### 页面结构
```
┌─────────────────────────┐
│      [返回]  个人资料    │  ← AppBar
├─────────────────────────┤
│                         │
│       ┌───────┐        │
│       │ 头像  │        │  ← 可点击更换
│       └───────┘        │
│       用户昵称 ✏️       │  ← 可点击编辑
│       user@email.com    │
│                         │
├─────────────────────────┤
│  账号绑定               │
│  ├─ Google  [已绑定]    │
│  └─ Apple   [未绑定]    │
└─────────────────────────┘
```

### 交互说明
| 触发元素 | 触发方式 | 行为 |
|---------|---------|------|
| 头像 | 点击 | 弹出相册选择器 |
| 昵称编辑图标 | 点击 | 弹出编辑对话框 |
| 返回按钮 | 点击 | 返回上一页 |

### 动画要求
- 页面进入：`AdaptiveTransitionType.rightToLeft`
- 头像更换：淡入淡出过渡
- 保存成功：Toast 提示

## 数据要求

### 用户信息模型
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | String | 是 | 用户 ID |
| nickname | String | 是 | 昵称 |
| email | String | 是 | 邮箱 |
| avatar_url | String? | 否 | 头像 URL |
| google_bound | bool | 是 | Google 绑定状态 |
| apple_bound | bool | 是 | Apple 绑定状态 |

## 验收标准

1. [x] 页面正确展示用户信息
2. [x] 点击头像可以选择相册图片
3. [x] 点击编辑可以修改昵称
4. [ ] 修改成功后有 Toast 提示
5. [ ] 加载失败时显示错误提示

## 备注

- 头像上传使用 Supabase Storage
- 昵称长度限制：2-20 个字符
