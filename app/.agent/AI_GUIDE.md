# AI 开发快速指南

## 新需求工作流程

```
┌──────────────────────────────────────────────────────────────┐
│                    新需求来了！                               │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  步骤 1：准备需求材料                                         │
│  ─────────────────────                                       │
│  □ JSX 原型（.agent/design/reference-design/src/）              │
│  □ PRD 需求文档（放入 .agent/specs/features/）                │
│  □ API 接口文档（放入 .agent/api/endpoints/）                 │
│                                                              │
│  提示：至少准备其中一项，最好全部齐全                           │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  步骤 2：与 AI 对话                                           │
│  ─────────────────                                           │
│  使用以下格式：                                               │
│                                                              │
│  /new-feature                                                │
│  - 功能：[功能名称]                                           │
│  - JSX 原型：.agent/design/reference-design/src/              │
│  - PRD：.agent/specs/features/xxx.md                        │
│  - API：.agent/api/endpoints/xxx.md                         │
│                                                              │
│  或者更简单：                                                 │
│  "根据这个设计稿 [截图] 和 API 文档创建 xxx 功能"              │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  步骤 3：AI 自动执行                                          │
│  ──────────────────                                          │
│  AI 会自动：                                                  │
│  1. 分析 JSX 原型源码（直接读取 JSX 组件）                     │
│  2. 解析 PRD 理解需求                                         │
│  3. 根据 API 生成 Model 类                                    │
│  4. 创建页面/组件代码                                         │
│  5. 添加路由                                                  │
│  6. 执行 build_runner                                        │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│  步骤 4：验证和调整                                           │
│  ───────────────                                             │
│  - 检查生成的代码是否符合预期                                  │
│  - 运行应用测试功能                                           │
│  - 如有问题，继续与 AI 对话调整                                │
└──────────────────────────────────────────────────────────────┘
```

---

## 常用斜杠命令

| 命令 | 用途 | 何时使用 |
|------|------|---------|
| `/new-feature` | 完整新功能开发 | 有 JSX 原型 + PRD + API |
| `/add-new-page` | 只添加页面 | 只有设计稿 |
| `/add-api-endpoint` | 只添加 API | 只有接口文档 |
| `/add-widget` | 添加组件 | 创建可复用组件 |
| `/run-build-runner` | 代码生成 | 修改了注解类后 |

## 文档放置位置

```
.agent/
├── specs/features/          ← PRD 需求文档放这里
│   └── [功能名].md
│
├── api/endpoints/           ← API 文档放这里
│   └── [模块名].md
│
└── design/                  ← AI 自动参考（无需手动添加）
    ├── DESIGN_SYSTEM.md
    └── interactions.md
```

## 文档模板

复制以下模板快速创建需求文档：

### PRD 模板（简化版）

```markdown
# [功能名称]

## 概述
[一句话描述]

## 功能需求
- [ ] 功能点 1
- [ ] 功能点 2

## UI 要求
[描述或指定 JSX 原型组件路径]

## 关联 API
[API 文档路径]

## 验收标准
1. [ ] 标准 1
2. [ ] 标准 2
```

### API 模板（简化版）

```markdown
# [模块名] API

## [接口名称]
- 路径: `POST /api/v1/xxx`
- 认证: 是

### 请求
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 是 | 名称 |

### 响应
```json
{ "id": "string", "name": "string" }
```
```

## 提示

1. **材料越全，AI 越精准** - JSX 原型 + PRD + API 都有时效果最好
2. **JSX 即设计稿** - AI 直接读取 JSX 源码翻译为 Flutter，无需 Figma
3. **迭代调整** - 生成代码后可以继续对话微调
4. **参考现有代码** - 告诉 AI "参考 xxx 页面的实现"能保持一致性
